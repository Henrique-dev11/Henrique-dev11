## 🔗 Projeto em destaque — Laço

O **Laço** é um projeto acadêmico mobile voltado à conexão entre **cuidadores e responsáveis por idosos**.

Estou utilizando o projeto como forma de aprender arquitetura e desenvolvimento de aplicações completas.

**Tecnologias utilizadas:**

`React Native` • `Expo` • `TypeScript` • `NestJS` • `Prisma` • `PostgreSQL` • `Docker`

Entre os conceitos estudados no projeto estão:

* API REST
* Modelagem de banco de dados
* Autenticação com JWT
* Hash de senhas com bcrypt
* Docker e containers
* Integração entre mobile, backend e banco de dados
* Git e GitHub
